# agent-skills: правила для агентов

Отвечай пользователю по-русски. Код и идентификаторы пиши по-английски.

Это репозиторий-источник скилов, которые ставятся в `~/.claude/skills` и `~/.agents/skills` через
junction-ссылки. Порядок работы описан в `skills/skills-curator/SKILL.md`, коротко:

- Набором управляет `skills.toml`. Папки `skills/<name>` со `SOURCE.md` скопированы из upstream: не
  правь их, следующий `update` их перезапишет, а `check` пометит правку как ошибку.
- После любой правки манифеста выполни `python tools/skillsync.py update <name>`, затем `check` (должно
  быть 0 ошибок) и `install`.
- Один `domain` — один скил. Прежде чем добавлять новый скил, проверь `status`: если задача уже занята,
  замени старый скил, а не добавляй второй.
- Удержанные (`held`) обновления принимай только после того, как пользователь посмотрел diff.
- Никогда не копируй скилы в `~/.claude/skills` руками.
- Коммить и пушь только по просьбе пользователя. Обновления скилов из upstream коммитит GitHub Action;
  локальный `auto_update.py` только делает `git pull` и `install`.
